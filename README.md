# Publication Status and Data Availability

The scientific manuscript describing the development, validation, and application of the Bacterial Microbial Index (BMI) is currently undergoing peer review. To ensure consistency between the published research and the resources provided in this repository, the complete R scripts, curated DB_BMI database, example datasets, documentation, and supplementary materials will be made publicly available here following publication of the article. This repository will serve as the official platform for accessing the BMI framework, supporting reproducibility, transparency, and future applications in microbial water-quality assessment and environmental monitoring.

# BMI
Bacterial Microbial Index (BMI): An R-based framework for assessing the relative representation of potentially health-relevant bacterial genera in aquatic environments using 16S rRNA and shotgun metagenomic sequencing data.


The Bacterial Microbial Index (BMI) is an R-based bioinformatic framework developed to assess the relative representation of potentially health-relevant bacterial genera in aquatic environments using DNA sequencing data from 16S rRNA gene amplicon and shotgun metagenomic approaches. The BMI uses genus-level taxonomic profiles generated with Kraken2 and a curated reference database (DB_BMI) to classify bacterial genera into two categories: Potentially Health-Relevant (PHR), comprising genera that include species of recognized or potential relevance to human or animal health, and Non-Health-Relevant (NHR), comprising genera primarily associated with environmental functions without established health relevance under the adopted classification criteria. The framework calculates two complementary metrics, BMI_abundance and BMI_richness, based on the relative abundance of sequencing reads and the proportion of bacterial genera classified as PHR, respectively. By default, the analysis considers the 150 most abundant bacterial genera (Top-150), although alternative Top-N thresholds can be evaluated. To run the BMI, users need R (RStudio recommended), the provided R analysis script, the curated DB_BMI.txt database, and one or more Kraken2 taxonomic report files placed in the designated input directory (kraken_reports/). The pipeline generates BMI metrics, taxonomic summaries, and graphical outputs to support comparative microbial water-quality assessment and environmental monitoring. Importantly, the BMI is intended as a complementary screening and prioritization tool and does not directly quantify pathogenic microorganisms, establish their viability, or replace conventional microbiological indicators and regulatory water-quality standards.
